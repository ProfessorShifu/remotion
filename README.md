# Remotion 3D Animation

A deterministic 3D animation built with [Remotion](https://remotion.dev) and [React Three Fiber](https://docs.pmnd.rs/react-three-fiber).

## What's inside

- Floating torus, icosahedron, and box with spring-based entrance animations
- Orbiting golden sphere
- Dynamic camera orbit around the scene
- Colored point lights and metallic materials
- Fully frame-driven (no random, no real-time clocks) for reproducible renders

## Commands

```bash
# Install
npm install

# Preview in Studio
npm run dev

# Render video
npx remotion render Scene out/video.mp4
```

## Stack

- Remotion 4
- @remotion/three
- @react-three/fiber
- three.js
